# HIGHWATCH

A desktop desk for DayZ server owners and staff: live server health and players, a terrain map with player trails, inventories, stashes, and base ownership, Expansion and LB Master support, tickets, Discord alerts, and an anti-cheat where every flag keeps its evidence and a replay. Evidence, not verdicts.

This repository holds release builds only. Highwatch is in early access and needs an access key to run.

## Download

Get the newest build from **[Releases](https://github.com/Sk3tch-Dev-Ux/Highwatch-Releases/releases/latest)**.

- **Windows:** `Highwatch-Setup-<version>.exe`. The installer is not signed yet, so SmartScreen warns. Choose More info, then Run anyway.
- **macOS (Apple silicon):** `Highwatch-<version>-arm64-mac.zip`. Unzip and move Highwatch to Applications. The app is not notarized yet: the first time, right-click it, choose Open, then Open again.

## Early access

On first launch Highwatch asks for your access key. Ask for one in our Discord: https://discord.gg/9ug8Yv4kg8

While it runs, Highwatch reports to us every five minutes so we can see that it works and help when it does not. The Early access card on the Integrations page lists exactly what is sent: your key label, app and system versions, the names and states of your connected servers and feeds, and error messages with keys, tokens, IP addresses, and Steam IDs removed. Nothing about your players, credentials, or chat is sent.

New builds show as a notice inside Highwatch. The ingest package and the server mod download from the Early access card once your key is active.
